AGSA Velour injection report marked duplicate on Google VRP. The eqli.java inner-intent extraction logic accepts attacker-controlled URIs via the data query parameter of dynact:// intents. Execution gap remains — Samsung Knox blocked Frida instrumentation, so the Velour module handler call chain could not be fully confirmed. The architecture is fascinating: a dynamic module system whose intent routing can be redirected by a single Uri.parse() call, isolated from the WebView rendering surface by intentional classloader separation. Google's defensive architecture is strong, but that one parsing operation is the chink.
